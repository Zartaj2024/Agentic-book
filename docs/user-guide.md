# User Guide: Physical AI Book

## Welcome to Physical AI Book

The Physical AI Book is an interactive textbook for learning robotics and AI concepts. This guide will help you navigate and make the most of all the features available.

## Getting Started

### Navigation

The textbook is organized into 6 core chapters:

1. **Introduction to Physical AI** - Fundamentals and key concepts
2. **Humanoid Basics** - Kinematics, DOF, and actuator systems
3. **ROS2 Fundamentals** - Nodes, topics, services, and the ROS2 graph
4. **Digital Twins** - URDF, Gazebo, and simulation environments
5. **Vision-Language-Action Systems** - RT-2, PaLM-E, and multimodal AI
6. **Capstone Project** - Complete implementation example

Use the sidebar navigation to move between chapters and sections.

## Interactive Features

### AI Tutor Chatbot

The AI tutor is accessible via the floating chat button in the bottom-right corner of the screen.

#### How to Use:
1. Click the chat button to open the tutor interface
2. Type your question about robotics or AI concepts
3. Receive responses based on the textbook content
4. View source chapters referenced in the response

#### Best Practices:
- Ask specific questions about concepts you're reading
- Reference specific chapters or topics in your questions
- Use the chatbot to clarify complex topics

### Text Selection Feature

Select text anywhere in the textbook to get instant access to the AI tutor.

#### How to Use:
1. Highlight any text in the textbook content
2. A small "Ask AI" tooltip will appear near your selection
3. Click the tooltip to open the chatbot with your selected text pre-filled
4. The AI will provide explanations based on the selected content

#### Best Practices:
- Use this feature when you encounter unfamiliar terms
- Select specific sentences or paragraphs for detailed explanations
- Combine with the general chatbot for broader context

### Search Functionality

Use the search bar (typically in the header) to find content across all chapters.

#### How to Use:
1. Click the search icon or press Ctrl+K (Cmd+K on Mac)
2. Type keywords or phrases
3. Browse results across all textbook chapters
4. Click on results to navigate directly to relevant sections

## Capstone Project

The final chapter includes a complete implementation of the "See object → Plan reach → Execute" pipeline. This demonstrates how all the concepts learned throughout the textbook integrate into a real robotic system.

### Components:
- Object detection using computer vision
- Motion planning with MoveIt2
- Trajectory execution on a robotic arm
- Complete ROS2 integration

## Troubleshooting

### Common Issues

#### Chatbot Not Responding
- Check your internet connection
- Refresh the page if the chat interface appears stuck
- Ensure you're asking questions related to textbook content

#### Search Not Working
- Wait a moment for search to initialize
- Check that you're using relevant keywords
- Try broader terms if getting no results

#### Text Selection Tooltips Not Appearing
- Ensure JavaScript is enabled in your browser
- Try refreshing the page
- Check browser compatibility
